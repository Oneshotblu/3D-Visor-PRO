3D VISOR PRO 1.1.0 - file per Windows
=====================================

3D Visor PRO 1.1.0 Setup.exe
  Programma di installazione. Al primo passo chiede se installare
  "solo per me" (nessun permesso di amministratore) oppure
  "per tutti gli utenti" del PC (serve l'amministratore).
  Crea il collegamento nel menu Start e la voce in "App installate"
  per disinstallarlo. Alla disinstallazione rimuove anche le
  associazioni dei file create dal visore.

3D Visor PRO 1.1.0.exe
  Versione portatile: un solo file, nessuna installazione.
  Si può copiare su una chiavetta e avviare con un doppio clic.
  (Usa il motore WebView2 già presente in Windows 10 e 11.)

Aprire sempre i file con il visore
  Dal programma: Impostazioni > Tipi di file. Ogni estensione
  (.step, .stp, .iges, .igs, .brep, .sldprt, .sldasm, .slddrw,
  .easm, .eprt, .edrw,
  .stl, .3mf, .obj, .ply, .glb, .gltf, .epub) si attiva o si
  disattiva da sola, "solo per me" o "per tutti gli utenti".
  Se in passato hai scelto un altro programma con "Apri con",
  Windows può chiedere una conferma: il visore apre la pagina
  giusta delle impostazioni di Windows.

Avvio con opzioni
  Visore3D.exe "percorso\file.step"   apre il file
  "3D Visor PRO.exe" --settings           apre subito le impostazioni

Misura
  Pulsante «Misura»: fai clic su vertici, spigoli o facce (modalità
  Auto, oppure scegli Vertice / Spigolo / Faccia / Punto). Con due
  elementi vedi la distanza; se due facce o spigoli non sono paralleli
  vedi anche l'angolo di inclinazione.

Spostare le parti di un assieme
  Pulsante «Sposta»: il programma chiede prima il consenso. Le parti si
  spostano e ruotano solo nella vista, il file non viene modificato.
  «Ripristina tutte» le rimette al loro posto.

File eDrawings (.easm, .eprt, .edrw)
  Letti con la libreria open source edrawings-kit (licenza Apache 2.0,
  vedi la cartella "licenze"). Funzionano nel programma per Windows,
  non nell'anteprima web.
